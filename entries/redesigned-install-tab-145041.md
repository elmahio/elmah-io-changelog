The *Install* tab on log settings has received a much-needed overhaul. The old design was from the time were elmah.io only supported ASP.NET, MVC, and Web API. Much happened since then with ASP.NET Core being introduced and great support for all major .NET logging frameworks.

The new design embeds install instructions for a set of popular web and logging frameworks with configuration code ready to copy and paste into your own projects:
