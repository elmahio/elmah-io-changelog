There's a new integration with elmah.io available for Isolated Azure Functions. Unlike the `Elmah.Io.Functions` package, `Elmah.Io.Functions.Isolated` works with the "new" out-of-process model available for Azure Functions. Check out the [new documentation](https://docs.elmah.io/logging-to-elmah-io-from-isolated-azure-functions/) on how to set it up, as well as built-in support or [logging heartbeats](https://docs.elmah.io/logging-heartbeats-from-isolated-azure-functions/).
