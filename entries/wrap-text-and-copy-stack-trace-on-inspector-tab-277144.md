The *Wrap text* and *Copy* buttons already known from the *Detail* tab have been added to the *Inspector* tab:

![Wrap text and copy stack trace on Inspector tab](/images/277144/675-a80c9b0be24effdb6966228718f011cb313acab8.png)

If you do not see the *Inspector* tab, make sure to upgrade your elmah.io client integration to version 5.
