For users on the Enterprise plan, we now show the latest Lighthouse and SSL score directly on the list of uptime checks. The Lighthouse score is an average of the five metrics from the latest Lighthouse report (if Lighthouse is enabled on the uptime check). The SSL score is the latest result from Qualys' SSL Server Test (if SSL expiration is enabled on the uptime check).
