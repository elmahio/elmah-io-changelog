We had a couple of requests for being able to update and remove a VAT number registered on a paying organization. Removing the VAT number is now possible for countries outside the EU. Updating a VAT number is now also possible, as long as the new VAT number still validates.

While looking at this we also improved the validation error to show an example from the chosen country to help you figure out the correct format to use:
