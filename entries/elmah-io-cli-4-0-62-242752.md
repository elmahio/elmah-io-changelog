We released a new version ([4.0.62](https://www.nuget.org/packages/Elmah.Io.Cli/4.0.62)) of the elmah.io CLI. The new version includes the following changes:

- Diagnose command support looking for elmah.io config in `web.config` files.
- Diagnose command support for `packages.config` files in addition to package references in `csproj` files.
- Diagnose command support for server-side diagnostics.
