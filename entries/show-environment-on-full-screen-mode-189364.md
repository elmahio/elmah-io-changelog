---
title: "Show environment on full-screen mode"
date: 2021-03-19T12:10:04Z
categories: [Improvement]
slug: show-environment-on-full-screen-mode-189364
---
The environment name (if any) has been added before the log name when switching to full-screen mode on the various tabs on the log search page. With this change, you no longer need to include the environment name in the log name.
