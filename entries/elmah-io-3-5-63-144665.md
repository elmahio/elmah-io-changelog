We released a new version ([3.5.63](https://www.nuget.org/packages/Elmah.Io/3.5.63)) of the `Elmah.Io`, `Elmah.Io.AspNet`, `Elmah.Io.Mvc`, and `Elmah.Io.WebApi` NuGet packages. Changes are primarily internally around the user agent communicated to the elmah.io API. The packages also bundle the newest stable version of the `Elmah.Io.Client` package.
