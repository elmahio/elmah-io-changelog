The **Filter Chrome Extensions** filter has been renamed to **Filter Browser Extensions** and now supports ignoring errors generated from both Chrome, Firefox, Edge, and Safari. With the filter currently enabled, only Chrome extension errors are ignored. To enable the new behavior, disable and enable the filter on the Log Settings page:
