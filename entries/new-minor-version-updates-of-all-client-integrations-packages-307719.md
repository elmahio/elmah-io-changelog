There are new minor version updates of all client integrations (like `Elmah.Io.AspNetCore` and `Serilog.Sinks.ElmahIo`). The only change is a dependency update to the newest `Elmah.Io.Client` package. If you are using a package versioned `5.2.x`, please either update to the newest version or install the newest `Elmah.Io.Client` in your project. Version `5.2.114` of `Elmah.Io.Client` had an internal issue as described [here](https://changelog.elmah.io/elmah-io-client-5-2-118-307322).
