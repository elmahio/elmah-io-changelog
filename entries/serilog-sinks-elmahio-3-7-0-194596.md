We released a new version ([3.7.0](https://www.nuget.org/packages/Serilog.Sinks.ElmahIo/3.7.0)) of the `Serilog.Sinks.ElmahIo` package. The new version includes the following changes:

- Running on the newest `Elmah.Io.Client` package.
- Support for setting `CorrelationId` through structured properties.
