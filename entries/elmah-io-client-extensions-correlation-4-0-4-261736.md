We released a new NuGet package named `Elmah.Io.Client.Extensions.Correlation`. The package will (with a single line of config) decorate log messages with a correlation ID, making it possible to correlate messages across multiple sites and services on the elmah.io UI. The package is available on [NuGet](https://www.nuget.org/packages/Elmah.Io.Client.Extensions.Correlation/4.0.4) and fully documented here: [How to correlate messages across services](https://docs.elmah.io/how-to-correlate-messages-across-services/).
