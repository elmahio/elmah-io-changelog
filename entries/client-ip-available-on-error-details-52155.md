The IP of the host causing an error/warning is now available directly on error details. Previously, you'd have to dig into the header details view, to find this information.

![Client IP](/images/52155/069-38025559821bfc3dfa6a6d30a6380b69b81314f5.gif)

Like shown on the animation, having the IP on the details view, makes it super easy to filter messages based on IP. As usual, hover the field and click the add or remove filter icons next to the IP.
