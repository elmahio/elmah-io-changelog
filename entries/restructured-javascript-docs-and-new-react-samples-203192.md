The JavaScript documentation has been re-structured to its own main menu item on [docs.elmah.io](https://docs.elmah.io/), making room for more specific help articles: https://docs.elmah.io/logging-to-elmah-io-from-javascript/.

While moving around, we also updated the [React documentation](https://docs.elmah.io/logging-to-elmah-io-from-react/) to reflect the recent changes happening in React and produced two new samples: [elmahio-react](https://github.com/elmahio/elmah.io.javascript/tree/main/samples/elmahio-react) and [elmahio-react-typescript](https://github.com/elmahio/elmah.io.javascript/tree/main/samples/elmahio-react-typescript).
