We released a new version ([4.1.12](https://www.nuget.org/packages/Serilog.Sinks.ElmahIo/4.1.12)) of the `Serilog.Sinks.ElmahIo` package. The new version includes the following changes:

- Running on the newest version of the `Elmah.Io.Client` package.
- Include readme in the NuGet package.
- Support for setting an application name on all log messages through options.
- Support for setting query string, server variables, and more through properties.
- Building on .NET 6.
- New sample for ASP.NET MVC.
