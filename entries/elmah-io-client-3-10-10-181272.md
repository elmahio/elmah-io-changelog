We released a new version ([3.10.10](https://www.nuget.org/packages/elmah.io.client/3.10.10)) of the `Elmah.Io.Client` package. The new version includes the following changes:

- Build moved from AppVeyor to GitHub Actions.
- SourceLink support on NuGet package.
- `CorrelationId` property added to log messages. The correlation ID is something that we are currently working on implementing on the app.
