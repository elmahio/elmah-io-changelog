The dropdown next to the search filters on the search view, contains a couple of features that you may haven't seen before: *Ignore future messages like this* and *Delete all messages like this*. Both features acts as batch actions on the currently shown set of messages. We just included the new search filters in both features. This means that when creating an ignore rule or batch deleting messages, any filters already added, are included in the query.
