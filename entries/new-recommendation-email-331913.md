A new email type has been added: New Recommendation. Enabling this email will send you an email when a new recommendation is created on a log or if a recommendation marked as fixed has been reopened. This way, you can monitor when the various elmah.io features add new recommendations.

The New Recommendation email can be enabled either when creating/editing a log from the dashboard (through [the redesigned dialog](https://changelog.elmah.io/redesigned-add-edit-log-dialog-331719)) or on the Emails tab on your profile.
