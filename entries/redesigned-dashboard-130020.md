We just launched a redesigned dashboard. The UI hasn't changed a whole lot, but we focused on a set of smaller improvements like better drag and drop, edit email subscriptions on edit log, included the new left menu, and more responsive design. While redesigning the page, we also prepared some foundations for some upcoming improvements and new features on the dashboard. Stay tuned on this changelog for more changes in the upcoming weeks.
