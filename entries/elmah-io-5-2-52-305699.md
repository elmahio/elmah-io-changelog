We released a new version ([5.2.52](https://www.nuget.org/packages/elmah.io/5.2.52)) of the `Elmah.Io`, `Elmah.Io.AspNet`, `Elmah.Io.Mvc`, and `Elmah.Io.WebApi` packages. The new version includes the following changes:

- Re-added support for setting a web proxy through `web.config`. More info [here](https://docs.elmah.io/logging-through-a-http-proxy/).
- Create installation during startup. An installation is a new term on elmah.io and will show up beneath the *Active installs* folder on the log settings page. More info [here](https://changelog.elmah.io/new-active-installs-page-304986).
- Newest `Elmah.Io.Client`.
- General code improvements by fixing all code suggestions.
