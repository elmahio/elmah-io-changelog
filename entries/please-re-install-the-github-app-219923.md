GitHub made a change in the way you need to provide personal access tokens for their API which will require a re-install of all GitHub apps on elmah.io. If you are using the GitHub app, please go ahead in re-install it on all logs.

We are looking into various ways of rolling this out automatically going forward, but for now, it's a manual process.
