A lot of elmah.io users have tried signing up for a new account when signing in with the wrong social provider. When logging in with a social account not already known, we have always created a new elmah.io user which typically isn't what the user intended. To avoid this, we have introduced a new modal that you will see if you log in with the wrong social provider going forward:
