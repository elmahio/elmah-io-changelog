We released a new version ([4.0.59](https://www.nuget.org/packages/Elmah.Io.Cli/4.0.59)) of the elmah.io CLI. The new version includes the following change:

- New `diagnose` command to help find missing or misconfigured elmah.io installations. Check out the updated documentation here: [Diagnose potential problems with an elmah.io installation](https://docs.elmah.io/cli-diagnose/). The command currently supports the following packages: `Elmah.Io`, `Elmah.Io.AspNetCore`, `Elmah.Io.Extensions.Logging`, `Elmah.Io.Log4Net`, `Elmah.Io.NLog`, and `Serilog.Sinks.ElmahIo`. A few rules are implemented for each package, and more will follow when new versions of the CLI are published.
