There's a new integration in the [elmah.io AppStore](https://elmah.io/features/appstore/): ClickUp. ClickUp is a tool for project management, tasks, collaboration, automation, and more. With the integration, you can have elmah.io automatically create tasks in ClickUp when new errors are registered. Check out the [documentation](https://docs.elmah.io/elmah-io-apps-clickup/) to set it up. The integration is currently in beta and we are very interested in collaborating with those of you who use or want to use ClickUp to get the best integration possible.
