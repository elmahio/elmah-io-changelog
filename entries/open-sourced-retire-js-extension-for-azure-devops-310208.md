We open-sourced our internal Azure DevOps extension for running [Retire.js](https://github.com/retirejs/retire.js/) as part of a build. Retire.js is an existing tool for detecting the use of JavaScript libraries with known vulnerabilities.

The source is available on our [GitHub](https://github.com/elmahio/azure-devops-retire) and the extension has been published to the [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=elmahio.retire-extension).
