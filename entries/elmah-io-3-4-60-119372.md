There is a [new stable version](https://www.nuget.org/packages/elmah.io/3.4.60) of the `Elmah.Io.*` packages for ASP.NET, ASP.NET MVC and ASP.NET Web API. Changes in this version:

- Improved internal use of HttpClient.
- Performance and stability improvements using the most recent `Elmah.Io.Client` package.

[Documentation](https://docs.elmah.io/logging-to-elmah-io-from-elmah/) has been updated to reflect all recent changes.
