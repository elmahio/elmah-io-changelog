We released a new version ([3.5.6](https://www.nuget.org/packages/elmah.io.log4net/3.5.6)) of the `Elmah.Io.Log4Net` package. The new version includes the following changes:

- Build moved from AppVeyor to GitHub Actions.
- SourceLink support on NuGet package.
- Running on the newest version of the `Elmah.Io.Client` package.
