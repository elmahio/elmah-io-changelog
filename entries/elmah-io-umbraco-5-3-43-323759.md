We released a new version ([5.3.43](https://www.nuget.org/packages/Elmah.Io.Umbraco/5.3.43)) of the `Elmah.Io.Umbraco` package. The new version includes the following changes:

- Updated `Umbraco.Cms` to 10.8.11 to avoid targeting a version with vulnerabilities.
- Newest `Elmah.Io.*` packages.
- General code improvements by fixing all code suggestions.
