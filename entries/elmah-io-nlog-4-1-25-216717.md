We released a new version ([4.1.25](https://www.nuget.org/packages/Elmah.Io.NLog/4.1.25)) of the `Elmah.Io.NLog` package. The new version includes the following changes:

- Running on the newest version of the `Elmah.Io.Client` package.
- Include readme in the NuGet package.
- Building on .NET 6 and new .NET 6 samples.
- Added documentation on NLog target.
