We released a new version ([3.9.12](https://www.nuget.org/packages/Elmah.Io.Extensions.Logging/3.9.12)) of the `Elmah.Io.Extensions.Logging` package. The new version includes the following changes:

- Build moved from AppVeyor to GitHub Actions.
- SourceLink support on NuGet package.
- Running on the newest version of the `Elmah.Io.Client` package.
