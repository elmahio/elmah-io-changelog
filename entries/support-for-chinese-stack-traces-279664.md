We pushed a new version ([1.2.0](https://www.npmjs.com/package/netstack.js/v/1.2.0)) of the open-source library [netStack.js](https://github.com/elmahio/netStack.js). The new version supports Chinese stack traces. The recent changes are available both inside of the elmah.io app as well as on the free [Stack Trace Formatter](https://elmah.io/tools/stack-trace-formatter/) tool ([here's a Chinese stack trace](https://elmah.io/tools/stack-trace-formatter/311bc3e8849a4ccf9de5bf3d7ae690a4/) if you want to see how it looks).
