We released a new version ([5.1.83](https://www.nuget.org/packages/Elmah.Io.Cli/5.1.83)) of the elmah.io CLI. It has been a while since we last announced a new version of this tool so let's summarize the changes since the last changelog:

- Diagnose command:
  - Replace the check on `UseRouting` with `MapControllerRoute`.
  - Support for detecting `UseElmahIo` call after `UseRouting` in `Elmah.Io.AspNetCore`.
  - Added `verbose` switch.
  - `Elmah.Io.Extensions.Logging` also checks correctly using to make sure that the right `AddElmahIo` method is called and not the one from `Elmah.Io.AspNetCore`.
  - Extended with useful hints plus a lot of general output improvements while diagnosing.
- Dataloader command:
  - Added more random data and included inspector on errors.
- Export command:
  - Now uses the `searchAfter` parameter which will allow for exporting more than 10k messages.
- Newest `Elmah.Io.Client`.
- Upgraded `Newtonsoft.Json` to v13.
