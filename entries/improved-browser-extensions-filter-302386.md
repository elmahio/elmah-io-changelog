The *Browser Extensions* filter has been updated with improvements and support for more types of extensions (primarily around Safari and Edge extensions). If you are unfamiliar with the *Browser Extensions* filter, it is intended to ignore JavaScript errors generated by extensions. It can be enabled/disabled on the *Filters* tab on the *Log Settings* page:

![Improved Browser Extensions filter](/images/302386/876-f2d7f8f86cf7c97ef6ac9d1220f1c089c3ee978e.png)

If you already have the filter enabled, you must disable and enable the filter to get the recent changes.
