We released a new version ([4.2.42](https://www.nuget.org/packages/Elmah.Io.AspNetCore/4.2.42)) of the `Elmah.Io.AspNetCore` package. The new version includes the following changes:

- Running on the newest version of the `Elmah.Io.Client` package.
- Updated `elmah.io.javascript` in tag helper to 3.7.0.
- Removed ASP.NET Core 2.1 sample.
