We released a new version ([3.7.66](https://www.nuget.org/packages/Elmah.Io.Extensions.Logging/3.7.66)) of the `Elmah.Io.Extensions.Logging` package. The new version includes the following changes:

- Better handling of logging non-string state values.
- Running on the latest stable version of `Elmah.Io.Client`.
