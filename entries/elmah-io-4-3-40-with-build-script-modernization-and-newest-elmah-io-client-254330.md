We released a new version ([4.3.40](https://www.nuget.org/packages/elmah.io/4.3.40)) of the `Elmah.Io`, `Elmah.Io.Mvc`, `Elmah.Io.WebApi`, and `Elmah.Io.AspNet` NuGet packages. The new version includes the following changes:

- Upgraded sample to .NET 4.8.
- Running on the newest version of `Elmah.Io.Client`.
- Build script modernization and package validation.
- Added documentation on the `ErrorLog` class.
