We released a new version ([5.3.60](https://www.nuget.org/packages/elmah.io/5.3.60)) of the `Elmah.Io`, `Elmah.Io.AspNet`, `Elmah.Io.Mvc`, and `Elmah.Io.WebApi` packages. The new version includes the following changes:

- Newest `Elmah.Io.Client`.
- General code improvements by fixing all code suggestions.
- Upgraded build image to Windows 2025.
