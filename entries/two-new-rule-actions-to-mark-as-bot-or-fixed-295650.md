Two new rule actions are available when creating rules: **Mark as bot** and **Mark as fixed**. As the names suggest, these actions can be used to automatically set the `isFixed` or `isBot` flag based on a query:

![Two new rule actions to mark as bot or fixed](/images/295650/742-a91dce2d75a6e5dfa8946de51bb98654ede43067.png)

The [documentation for rules](https://docs.elmah.io/creating-rules-to-perform-actions-on-messages/) has been updated to reflect the new actions.
