We released a new version ([5.1.19](https://www.nuget.org/packages/Elmah.Io.Wpf/5.1.19)) of the `Elmah.Io.Wpf` package. The new version includes the following changes:

- Remove dummy bookkeeping object added by the Dispatcher.
- Newest `Elmah.Io.Client`.
- Newest `Newtonsoft.Json` to avoid running on vulnerable package versions.
- Building on .NET 8.
- New .NET 8 sample.
- Upgraded `Microsoft.SourceLink.GitHub` to `8.0.0`.
- Several code improvements after running Sonar checks. This is all internal so no need for code changes are required by you.
