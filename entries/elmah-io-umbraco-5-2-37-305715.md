We released a new version ([5.2.37](https://www.nuget.org/packages/Elmah.Io.Umbraco/5.2.37)) of the `Elmah.Io.Umbraco` package. The new version includes the following changes:

- Building and testing on .NET 9. Also added a new .NET 9 sample.
- Newest `Elmah.Io.*` packages.
- Updated `Umbraco.Cms` to version `10.8.7`. That's the minimum version so you are free to pick a newer version of Umbraco.
- General code improvements by fixing all code suggestions.
