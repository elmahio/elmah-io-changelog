We released a new version ([3.8.11](https://www.nuget.org/packages/elmah.io.nlog/3.8.11)) of the `Elmah.Io.NLog` package. The new version includes the following changes:

- Build moved from AppVeyor to GitHub Actions.
- SourceLink support on NuGet package.
- Running on the newest version of the `Elmah.Io.Client` package.
- Include exception data dictionary in log message.
- Updated ASP.NET Core sample to 3.1.
