We launched a new feature called **Bot Detection**. With Bot Detection we automatically mark log messages generated by bots with a new flag named `isBot`. You can manually update a message group to be marked as a bot message too and you can create both searches and rules based on the new field. More information available here: [Bot detection](https://docs.elmah.io/bot-detection/).
