We released a new version ([5.1.89](https://www.nuget.org/packages/Elmah.Io.Cli/5.1.89)) of the elmah.io CLI. The new version includes the following feature:

- When running the `diagnose` the system clock is verified against the actual clock. If it is out of sync the command will show a warning. This is to help catch the scenario where log messages appear as past or future messages because the originating machine clock is wrong.
