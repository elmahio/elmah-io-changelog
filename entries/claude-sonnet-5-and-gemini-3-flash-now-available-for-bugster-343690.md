Bugster now supports Claude Sonnet 5, and we have replaced Gemini 3 Flash Preview with Gemini 3 Flash. You will find the configuration for Bugster on the Organization Settings page.

The list is getting quite long again. If you are using a deprecated model, please upgrade, as Bugster won't be able to answer questions once we remove those models.
