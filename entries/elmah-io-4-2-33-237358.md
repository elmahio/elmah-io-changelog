We released a new version ([4.2.33](https://www.nuget.org/packages/elmah.io/4.2.33)) of the `Elmah.Io` package. The new version includes the following changes:

- Running on the newest version of the `Elmah.Io.Client` package.
- Better support for automatically configuring the package even though ELMAH is already installed.
