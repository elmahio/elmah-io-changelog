Organization admins can now send verification emails from *Organization Settings*, making it easy to get existing users to verify their email address. We don't require verified emails for users created before adding this feature, but you can use it if you want to verify emails for all users in your existing organization.

![Send email verification from organization settings](/images/321856/043-07a630a4d622d50c5abeedcf58e20135e648932b.png)

For more information, check out the [updated documentation](https://docs.elmah.io/managing-organisations-and-users/#email-validation).
