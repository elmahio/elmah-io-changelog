If you are using a newer version of the client integrations, your application creates an "Installation" when configuring each logger (more info [here](https://changelog.elmah.io/new-active-installs-page-304986)). We just released a new tab on the extended message details view when the source of a log message is known. This means you can see which logger originally stored a log message with all of the settings and properties already available on *Active installs*:
