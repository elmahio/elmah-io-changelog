We released a new version ([3.12.24](https://www.nuget.org/packages/Elmah.Io.AspNetCore/3.12.24)) of the `Elmah.Io.AspNetCore` package. The new version includes the following changes:

- Support for [Breadcrumbs](https://docs.elmah.io/logging-breadcrumbs-from-asp-net-core/).
- Newest `Elmah.Io.Client`.
- Set `Took` property on health check results.
- Include more server variables by using ASP.NET Core *Features*.
- Updated to version 3.5.0 of `Elmah.Io.JavaScript` in tag helper.
