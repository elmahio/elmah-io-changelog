There's a new SQL tab available on log message details when SQL is logged as part of the message:

![SQL tab on log messages involving database commands](/images/278652/695-53fe6cff29632d7c519acf566840034cd9e6cab6.png)

The content is automatically pulled from log messages generated by Entity Framework and other ORMs and libraries built on top of the `System.Data` namespace.

For more information check out [How to get the SQL tab to show up](https://docs.elmah.io/how-to-get-the-sql-tab-to-show-up/).
