One of the most requested features has just been pushed to production: Organization administrators can now set up emails for users in the organization. elmah.io has always been based on users setting up which emails to receive on their profile. While this is still possible, organization administrators now have this possibility too. By clicking the green gear icon next to the user on the Users tab on the organization settings page, there is a new tab to set up emails:
