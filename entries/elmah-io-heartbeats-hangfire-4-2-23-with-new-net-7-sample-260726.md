We released a new version ([4.2.23](https://www.nuget.org/packages/Elmah.Io.Heartbeats.Hangfire/4.2.23)) of the `Elmah.Io.Heartbeats.Hangfire` NuGet package. The new version includes the following changes:

- Build script modernization, build on .NET 7, and package validation.
- New sample for ASP.NET Core 7.
- Running on the newest version of `Elmah.Io.Client`.
