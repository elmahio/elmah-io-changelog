The Add/Edit log control available from the dashboard has been redesigned. Instead of the flipping card effect, this feature is now presented as a slide-in. This makes the feature match other places where data is edited, while also creating more room for new content. One addition already made is the option to select whether the log should be included in the individual or combined daily digest emails. A new email type will be added soon, so stay tuned for updates.
