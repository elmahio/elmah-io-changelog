We released a new version ([3.4.43](https://www.nuget.org/packages/elmah.io.log4net/3.4.43)) of the `Elmah.Io.log4Net` package. The new version includes the following changes:

- Add data entries from a logged exception.
- More ways to fill the `hostname` field.
- Don't log `NOT AVAILABLE` values from log4net.
- ASP.NET Core 3.1 sample.
- Running on the latest stable version of `Elmah.Io.Client`.
