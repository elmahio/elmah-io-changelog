Bugster, the helpful AI agent on elmah.io, just received an improvement that can significantly improve the answers to your questions about your logs: source control access. In the Bugster configuration, you can pick either GitHub or Azure DevOps to allow Bugster to look up source files in your repositories. The connection is configured on the Organization Settings page, while picking a repository is available on the Log Settings page. This allows for configuring the connection once and then picking individual (or the same) code repositories per log.

Check out the updated documentation to learn how to set it up: [Give Bugster access to your source code](https://docs.elmah.io/how-to-configure-and-use-bugster/#give-bugster-access-to-your-source-code).
