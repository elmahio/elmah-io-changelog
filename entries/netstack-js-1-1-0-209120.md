We released a new version ([1.1.0](https://www.npmjs.com/package/netstack.js/v/1.1.0)) of the `netStack.js` library. That's the jQuery plugin that nicely formats stack traces within the elmah.io app and the [Stack Trace Formatter](https://elmah.io/tools/stack-trace-formatter/). The new version contains support for Russian stack traces and a bugfix. Let us know if it causes any problems.

If you need to format and syntax highlight .NET stack traces in your own software, take a look at [netStack.js](https://github.com/elmahio/netStack.js).
