We released a new version ([3.4.1](https://github.com/elmahio/elmah.io.javascript/releases/tag/3.4.1)) of the `Elmah.Io.JavaScript` package. The new version includes the following changes:

- `message` builder function accept error to use for prefilling.
- Added `correlationId` and `titleTemplate` fields in TypeScript mapping.

The new release is available on [GitHub](https://github.com/elmahio/elmah.io.javascript/releases/tag/3.4.1), [npm](https://www.npmjs.com/package/elmah.io.javascript/v/3.4.1), and [NuGet](https://www.nuget.org/packages/elmah.io.javascript/3.4.1).
