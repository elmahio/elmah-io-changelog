We needed a tool able to merge two JSON files, so we built one for you to use as well. The issue with many existing tools is that they perform the merge on the backend and therefore share sensitive data embedded in the JSON with the tool's provider. Our JSON Merger runs everything in the browser.

Use it for free at: [JSON Merger](https://elmah.io/tools/json-merger/)
