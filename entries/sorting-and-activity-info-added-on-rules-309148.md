To help get a better overview of Rules, a list that can quickly grow in size, we have added a new sorting option. You can sort the list both ascending and descending by: Name, Type, and Created date:

![Sorting](/images/309148/604-57e4f23938ca4c5565fa45727f0933b4b6e0a5c4.png)

Sorting by Created will only work on rules created after introducing the new sorting feature. Likewise, new rules will have an info icon in the lower right corner where you can see who created the rule and when:

![Info popup](/images/309148/605-8c0821e3e931331eeeb205466de99f930e0919b4.png)
