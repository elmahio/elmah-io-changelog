There's a new *Share* button on .NET stack traces within the elmah.io app. With this button you can quickly share a link to a stack trace logged by your app, using the [elmah.io Stack Trace Formatter](https://elmah.io/tools/stack-trace-formatter/). The stack trace will be visible for everyone with the generated link, so only share a stack trace if it doesn't contain sensitive information about your application (like folder structures and file names).
