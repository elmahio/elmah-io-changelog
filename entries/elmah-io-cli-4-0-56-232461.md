We released a new version ([4.0.56](https://www.nuget.org/packages/Elmah.Io.Cli/4.0.56)) of the elmah.io CLI. The new version includes the following change:

- New `clear` command to help delete unwanted messages from one or more logs. The [documentation](https://docs.elmah.io/cli-clear/) has been extended to cover the command.
- Re-ordered commands alphabetically.
- Running on the newest version of `Spectre.Console`.
