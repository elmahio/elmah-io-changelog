We released a new version ([5.0.38](https://www.nuget.org/packages/Serilog.Sinks.ElmahIo/5.0.38)) of the `Serilog.Sinks.ElmahIo`package. The new version includes the following change:

- Re-introduced the `WriteTo` method accepting API key and log ID as strings to allow for configuration through `Serilog.Settings.Configuration`.
