Our integration for Umbraco just became a whole lot better. With the [recent version](https://www.nuget.org/packages/elmah.io.umbraco/3.2.34), we also log errors generated by Web API. You don't need to configure anything, just extend `UmbracoApiController` and all exceptions are automatically picked up and presented at elmah.io.

Get started here: [Logging to elmah.io from Umbraco](https://docs.elmah.io/logging-to-elmah-io-from-umbraco/).
