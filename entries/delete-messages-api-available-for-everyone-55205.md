API endpoints for deleting a single or multiple messages, are now available for everyone (previously only available on the Enterprise plan):

![Delete API](/images/55205/223-14b0487ab3f8171d165f5bb2e0e5f9215696c197.png)

Cleaning up logs won't reset your message limit, but it can help you get a better overview, by removing all messages matching a specified query, etc.

Visit https://api.elmah.io/swagger/ for details.
