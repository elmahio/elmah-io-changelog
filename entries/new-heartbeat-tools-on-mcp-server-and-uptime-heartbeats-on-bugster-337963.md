We have added two new heartbeat tools to the [MCP server](https://mcp.elmah.io/). With these tools, you can check the current heartbeat status in a log and get detailed information about a specific heartbeat. Like _"Do I have any failing heartbeats right now?"_ or _"Why did the heartbeat X fail one hour ago?"_.

We have also made both the [Uptime](https://changelog.elmah.io/uptime-tools-now-available-on-the-mcp-server-336701) and Heartbeat tools available to Bugster, so that you can ask questions within the elmah.io UI:
