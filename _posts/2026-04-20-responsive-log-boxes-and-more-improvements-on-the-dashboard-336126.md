We have added two changes to the dashboard. The most visible change is increasing the number of possible log boxes shown per row. The view has always been responsive, but with a maximum of 4 boxes per row. On higher resolutions, we now show up to 8 boxes per row. You can change Zoom settings in Windows or in the browser if you want to increase/decrease the number of boxes shown on a big screen.

To make the scale clearer, we now show the max log message counter on log boxes when in kiosk/full-screen mode. When running in normal mode, you can still hover each log box to show the counter.
