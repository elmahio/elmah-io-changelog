There's an improved options API for configuring elmah.io in ASP.NET Core. The new API follows how other middleware packages are configured and allows for configuration through `appsettings.json`.

Check out [Migrating to the options pattern in the client for ASP.NET Core](https://blog.elmah.io/migrating-to-the-options-pattern-in-the-client-for-asp-net-core/) as well as the [updated documentation](https://docs.elmah.io/logging-to-elmah-io-from-aspnet-core/) for details on how to migrate.
