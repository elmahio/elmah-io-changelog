In case you need to get a better overview of IIS log files generated in the W3C Extended Log File Format we have built a new viewer available as a free tool: [W3C Extended Log File Format Viewer](https://elmah.io/tools/w3c-extended-log-file-format-viewer/).

We are also looking into (maybe) creating a set of importers inside the elmah.io app or through the CLI. Make sure to reach out if you have any specific log file formats that you'd like to import into your elmah.io log.
