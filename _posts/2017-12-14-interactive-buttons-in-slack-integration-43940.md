Getting Slack notifications when new errors are logged on elmah.io has always been one-way. If you wanted to do anything, you would need to go to elmah.io. With the improved Slack app, hiding, marking as fixed and deleting an error is available right there on Slack:

![slack-actions.jpg](/images/43940/784-aaa22b0604c3e064a7f7a216a90212e76b5adc04.png)

To use the new buttons, please re-install the Slack app.
