We released a new version ([4.0.0](https://www.npmjs.com/package/elmah.io.javascript/v/4.0.0)) of the `Elmah.Io.JavaScript` package. The new version includes the following change:

- Support for logging errors from promises.
- Setting a cause in an Error will print as part of the stack trace (works like inner exceptions in C# now).
- Type and Source will get the type and source of the most inner cause.
- Support for [Exception Inspector](https://changelog.elmah.io/announcing-the-new-exception-inspector-265594).
- ASP.NET Core 6 sample.
- Fixed bug where sending a non-Error object to one of the log methods accepting an Error would cause an exception.
