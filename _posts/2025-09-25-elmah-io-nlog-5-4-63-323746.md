We released a new version ([5.4.63](https://www.nuget.org/packages/Elmah.Io.NLog/5.4.63)) of the `Elmah.Io.NLog` package. The new version includes the following changes:

- Made an `OnInstallation` hook available in the target.
- Added TargetFrameworks net461 since net45 is not included in Visual Studio 2022 by default.
- Newest `Elmah.Io.Client`.
- General code improvements by fixing all code suggestions.
- Upgraded build image to Windows 2025.
