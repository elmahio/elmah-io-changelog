A month ago, we launched JavaScript logging in private beta. We are so happy with the current state of the feature, that we are ready to invite everyone to join. The installation is documented in the new help article [Logging to elmah.io from JavaScript](https://docs.elmah.io/logging-to-elmah-io-from-javascript/). The `elmah.io.js` script is available through manual download, CDN, npm, NuGet and the new Library Manager in Visual Studio 2017.8. Example code can be found in the [elmah.io.js samples](https://github.com/elmahio/elmah.io.js/tree/master/samples) on GitHub. Let us know what you think.
