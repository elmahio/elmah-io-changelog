The [elmah.io AI plugin](https://docs.elmah.io/elmah-io-ai-plugin/) is now available for ChatGPT and Codex, in addition to Claude Code and Cursor. Install it from the [plugin directory](https://chatgpt.com/plugins/plugin_asdk_app_6ad86e64d898819183e28056430982b9) and sign in with your elmah.io account.

The plugin bundles the elmah.io MCP server with four skills: `debug-production-error`, `post-deployment-check`, `investigate-frequent-errors`, and `check-uptime-status`. The `deployment-watchdog` agent is not included, since OpenAI plugins don't support agents.

Read more about the plugin and how to install it on the [docs page](https://docs.elmah.io/elmah-io-ai-plugin/).
