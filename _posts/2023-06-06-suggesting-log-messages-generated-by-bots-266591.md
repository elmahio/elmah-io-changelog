We have started suggesting log messages generated by bots based on some obvious parameters (like requesting non-existing `.php` files). By marking a log message as generated by a bot, you can set up elmah.io to automatically hide future instances of this message. Or you can create a view filtering out noise by excluding log messages generated by bots.

![Suggesting log messages generated by bots](/images/266591/225-3e6b5e838da63c15d091e532a1c7b2938175be7d.png)

The existing bot detection feature, available for Enterprise customers, is still there and works even better now. By including log messages matching the new criteria, automatic bot detection will detect more bot requests.
