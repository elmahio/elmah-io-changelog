We released a new version ([5.1.88](https://www.nuget.org/packages/Elmah.Io.Cli/5.1.88)) of the elmah.io CLI. Besides a lot of code fixes and cleanup, the new version includes the following feature:

- Support for specifying a proxy host and port on most commands. This makes it easier to use the CLI in environments with limited or no outgoing internet connection (like some test and production environments).
