The GitHub integration has been extended to include more fields as well as a link back to the full error details on elmah.io. To get the new integration, edit and save any existing GitHub apps or set it up using a personal access token or a fine-grained token as explained in the [documentation](https://docs.elmah.io/elmah-io-apps-github/).
