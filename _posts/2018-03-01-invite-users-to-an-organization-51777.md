Adding a user to your organization, previously required an already signed up user. With the recent release, inviting new users is now possible by inputting an email beneath *Add user* on Organization Settings:

![Invite user](/images/51777/906-72282b4703d1ae20bb9bdaf9f651764c9b76f821.gif)

The inputted email will receive an invitation. When signing up for elmah.io, the user is automatically added to the organization with the chosen access level.

To make sure that no-one is given log access without your knowledge (someone could intercept the invite email), the invite link only works once and requires an organization admin to assign log access after the user signed up.

⚠️ Inviting new users as Administrator, will allow them to assign log access themselves after signing up
