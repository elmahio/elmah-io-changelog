We added a sample showing how to log from a Blazor Web App to the `Elmah.Io.Blazor.Wasm` repository. It combines `Elmah.Io.Extensions.Logging` (plus `Elmah.Io.AspNetCore.ExtensionsLogging`) in the Server project with `Elmah.Io.Blazor.Wasm` in the Client project, covering all four Blazor render modes: Static Server, Interactive Server, Interactive WebAssembly, and Interactive Auto. Blazor Web App is now the first section on the Blazor docs page: [https://docs.elmah.io/logging-to-elmah-io-from-blazor/](https://docs.elmah.io/logging-to-elmah-io-from-blazor/)
