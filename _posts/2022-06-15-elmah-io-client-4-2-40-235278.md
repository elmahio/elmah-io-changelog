We released a new version ([4.2.40](https://www.nuget.org/packages/Elmah.Io.Client/4.2.40)) of the `Elmah.Io.Client` package. The new version includes the following changes:

- Moved private logic to convert `Severity` enum to `string` to a public extension method.
- Rebuild client from the latest swagger spec (documentation changes only).
- Added missing documentation on types.
