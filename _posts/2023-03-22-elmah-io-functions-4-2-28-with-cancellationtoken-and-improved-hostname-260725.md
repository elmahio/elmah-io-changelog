We released a new version ([4.2.28](https://www.nuget.org/packages/Elmah.Io.Functions/4.2.28)) of the `Elmah.Io.Functions` NuGet package. The new version includes the following changes:

- Build script modernization and package validation.
- `CancellationToken` support.
- Added more ways of resolving hostname.
- Running on the newest version of `Elmah.Io.Client`.
