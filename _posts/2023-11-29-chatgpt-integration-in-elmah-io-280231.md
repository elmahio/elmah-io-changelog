To celebrate Sam Altman's return to OpenAI, we are launching ChatGPT for elmah.io. Ok, the situation at OpenAI doesn't have anything to do with launching this feature, but now is an interesting time for AI for sure.

With the new ChatGPT app for elmah.io, you can get help resolving issues directly from the elmah.io UI. Simply install the ChatGPT app and input your OpenAI API key and pick a language modal of choice (we currently support GPT-3.5-Turbo and GPT-4). A new *AI* tab will show up on errors valid for looking up ChatGPT help:

![ChatGPT integration in elmah.io](/images/280231/785-e8b557b4087ffc4307869def70d112bd91bb382b.gif)

The app is currently in beta. As always when using AI, think about what you want to share with OpenAI. When requesting help from within elmah.io we share the stack trace. In the ChatGPT app, you can enable sharing of source code and SQL for a better answer from ChatGPT.
