There's a [new API endpoint](https://api.elmah.io/swagger/index.html#/UptimeChecks/UptimeChecks_GetAll) for pulling the status of all uptime checks within your organization. The endpoint is currently in closed beta. If you want to build something fun with the current status of your uptime checks, feel free to request access 🙌
