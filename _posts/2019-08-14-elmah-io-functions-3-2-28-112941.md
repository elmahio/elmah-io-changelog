We released a [stable version](https://www.nuget.org/packages/Elmah.Io.Functions/3.2.28) of our integration with Azure Functions: `Elmah.Io.Functions`. New features are:

- Support for Azure Functions v2.
- New options pattern with support for message hooks and application name.
- Performance and stability improvements using the latest `Elmah.Io.Client`.

Azure Functions v1 is no longer supported. If you are not on v2 already, please stay on `3.1.x`. We are not planning to release any more bugfixes on the old version, though.

Check out the [documentation](https://docs.elmah.io/logging-to-elmah-io-from-azure-functions/) for more details. Thank you to Peter Obel for writing most of the code in this release 👍
