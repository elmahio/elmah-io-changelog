There's a new version of the elmah.io extension for Visual Studio 2022 ([3.4.30](https://marketplace.visualstudio.com/items?itemName=elmahio.elmahiobrowser2022)). The version includes a new options page where you can manually add and remove an elmah.io API key to avoid going through the login flow.
