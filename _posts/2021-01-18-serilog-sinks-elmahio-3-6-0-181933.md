We released a new version ([3.6.0](https://www.nuget.org/packages/Serilog.Sinks.ElmahIO/3.6.0)) of the `Serilog.Sinks.ElmahIo` package. The new version includes the following changes:

- SourceLink support on NuGet package.
- Running on the newest version of the `Elmah.Io.Client` package.
- Using the new `ToDataList` method from the client that collects all exception properties recursively.
- New sample for ASP.NET Core 3.1.
