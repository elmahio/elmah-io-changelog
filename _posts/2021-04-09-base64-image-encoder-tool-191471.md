We published yet another free tool: [Base64 image encoder](https://elmah.io/tools/base64-image-encoder/). Easily convert images to Base64 strings. There are so many online tools that can do this already, but we wanted to build one that both supports drag and drop, and besides the usual HTML and CSS output also generates XML and JSON.
