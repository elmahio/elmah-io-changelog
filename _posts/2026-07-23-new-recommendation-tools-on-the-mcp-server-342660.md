We have added two new tools to the MCP server: `recommendations_list` and `recommendations_get_details`. With these tools, your AI client can get recommendations created on either a log or the organization from elmah.io. Recommendations include issues created by the toggles on uptime checks (SSL expiration, etc.), available client updates, and much more not captured as log messages.
