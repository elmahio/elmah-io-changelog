We published a free tool to quickly generate an MD5 hash from a string: [MD5 Encoder](https://elmah.io/tools/md5-encoder/). Convert an input string to MD5 directly in the browser. No server-round trip and no logging of your source string.

![Md5 Encoder](/images/194517/295-632d35604bb11fb33781f238342750c18f9a6927.png)

Besides the convert feature which a lot of tools out there already do, we spiced this up with some C# goodies. When inputting a string, the tool automatically generates C# code to insert directly into your program. We also provide you with an extension method to easily generate MD5 hashes.
