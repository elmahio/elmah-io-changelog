We released a new version ([3.2.0](https://github.com/elmahio/elmah.io.javascript/releases/tag/3.2.0)) of the `elmah.io.javascript` package. The new version includes the following changes:

- Support throwing strings and integers
- Write to console log when misconfigured
- Fixed bug where changes in detail field through the message event were overwritten
