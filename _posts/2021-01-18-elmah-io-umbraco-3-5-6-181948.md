We released a new version ([3.5.6](https://www.nuget.org/packages/elmah.io.umbraco/3.5.6)) of the `Elmah.Io.Umbraco` package. The new version includes the following changes:

- Build moved from AppVeyor to GitHub Actions.
- SourceLink support on NuGet package.
- Running on the newest versions of the `Elmah.Io.Client`, `Elmah.Io`, and `Serilog.Sinks.ElmahIo` packages.
