To better help with XDT problems, we have released a new tool: [Web.config Transformation Tester](https://elmah.io/tools/webconfig-transformation-tester/). The transformation tester creates an online experience, similar to the Preview tab in Visual Studio. By inputting a `Web.config` and a transform file (like `Web.release.config`), you will see a diff of the changes produced by the transformation file:
