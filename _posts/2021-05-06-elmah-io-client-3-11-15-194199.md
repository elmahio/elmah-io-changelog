We released a new version ([3.11.15](https://www.nuget.org/packages/Elmah.Io.Client/3.11.15)) of the `Elmah.Io.Client` package. The new version includes the following changes:

- Added an optional `Took` property on heartbeats. The property can be set during a heartbeat to indicate how long it took (in ms). The value is shown on the heartbeat history page.
- Added list of breadcrumbs on log messages. Breadcrumbs is a new elmah.io feature that will be announced soon.
- Fixed a bug where returning `200` from the create message endpoint would throw an exception.
