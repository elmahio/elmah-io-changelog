We released a new version ([5.3.131](https://www.nuget.org/packages/Elmah.Io.Client/5.3.131)) of the `Elmah.Io.Client` package. The new version includes the following changes:

- Built with the newest version of NSwag, which contains several code improvements (code is still backwards-compatible).
- Added `OnInstallation` event plus extended `CreateInstallation` with a list of environment variables. Environment variables will be fully available in the upcoming `Elmah.Io.Client` v6.
- Added missing JSON settings for `SourceMapsClient`.
- Added `EnvironmentVariablesHelper`. This is primarily used within the `Elmah.Io.*` client integrations.
- Upgraded build image to Windows 2025.

Unless security issues are identified, this will be the last version of `Elmah.Io.Client` v5. The upcoming v6 will contain several improvements and run on a new major version of the elmah.io API.
