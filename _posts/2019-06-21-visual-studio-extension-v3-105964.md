Good news for all of you elmah.io Visual Studio extension users out there. We released a major update, now available through the [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=elmahio.elmahio) and from within Visual Studio. The new version includes the following features:

- API v3 support (you no longer need to enable API v2 access).
- Remember user.
- Search filters.
- Multiple organizations support.
- Authorize access to an organization from within the extension.
