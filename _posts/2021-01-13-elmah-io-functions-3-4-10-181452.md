We released a new version ([3.4.10](https://www.nuget.org/packages/Elmah.Io.Functions/3.4.10)) of the `Elmah.Io.Functions` package. The new version includes the following changes:

- Build moved from AppVeyor to GitHub Actions.
- SourceLink support on NuGet package.
- Running on the newest version of the `Elmah.Io.Client` package.
- Updated samples to Functions v3 runtime.
- Configurable timeout when communicating with the elmah.io API.
- Log function name in Data.
