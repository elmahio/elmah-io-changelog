We released the third beta of our integration from JavaScript, [elmah.io.javascript](https://github.com/elmahio/elmah.io.javascript) (the artist formerly known as `elmah.io.js`). The new version contains support for JavaScript sourcemaps as well as fixes for all known bugs. The [Logging to elmah.io from JavaScript](https://docs.elmah.io/logging-to-elmah-io-from-javascript/) document and all [samples](https://github.com/elmahio/elmah.io.javascript/tree/master/samples), have been updated to reflect the recent changes.
