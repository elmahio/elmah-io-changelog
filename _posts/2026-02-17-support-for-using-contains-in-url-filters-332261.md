Support for using the *Contains* and *Does not contain* conditions has been extended to also cover the *URL* field when adding new filters to the search page. You can use this to find log messages that contain parts of a URL. Notice that you can also use wildcards, like in the following example that finds all URLs with a file extension of `.php`:
