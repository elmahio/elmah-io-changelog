We have made three minor changes to the extended log message view:

- Added the star indicating if a log message is considered new directly on message details.
- Added the domain name (when known) on the URL field.
- Renamed *Error* to *Type* to make the name consistent between the API, the column name on the search page, and the extended log message view.
