Support for Azure Functions v2 and above is now available in a prerelease of the `Elmah.Io.Functions` package. We have moved entirely to the new dependency injection system recently launched by Microsoft. For more details check out the updated documentation: [https://docs.elmah.io/logging-to-elmah-io-from-azure-functions/](https://docs.elmah.io/logging-to-elmah-io-from-azure-functions/)
