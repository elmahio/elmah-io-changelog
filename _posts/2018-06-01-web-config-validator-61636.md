We just relaunched our [Web.config validator](https://elmah.io/tools/configvalidator/). Previously, you could only use it to validate the ELMAH part of a `Web.config` file. With the new version, everything in the configuration file is validated against the correct schema and errors/warnings are listed. More details and a demo available here: [https://blog.elmah.io/web-config-validator/](https://blog.elmah.io/web-config-validator/).
