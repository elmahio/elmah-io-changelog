We have extended the elmah.io CLI with a new command to load 50 dummy log messages into a log. Using dummy messages is a great way to fill an elmah.io log with demo data without having to integrate with an application and producing messages manually.

The documentation has been updated here: https://docs.elmah.io/cli-dataloader/.
