app.elmah.io and the [Stack Trace Formatter](https://elmah.io/tools/stack-trace-formatter/) now support formatting and highlighting Spanish stack traces. Both features are built on top of [netStack.js](https://github.com/elmahio/netStack.js), our open-source JavaScript library for syntax highlighting .NET stack traces.
