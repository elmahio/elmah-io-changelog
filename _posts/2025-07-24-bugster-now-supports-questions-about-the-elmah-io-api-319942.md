Bugster, our AI-powered chatbot, now supports questions about the elmah.io API. You can ask about the various endpoints, which input parameters to use, response status codes, and more. Since Bugster has access to both the API and the client integrations, you can ask it to combine the two by asking for something like client code in both PowerShell, using the API directly, and C#, using the `Elmah.Io.Client` package.
