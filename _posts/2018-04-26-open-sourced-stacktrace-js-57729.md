We open sourced our new jQuery plugin stacktrace.js. stacktrace.js makes it easy to format .NET stacktraces directly in the browser:

```js
$('.stacktrace').stackTrace();
```

Result:

![Formatted stacktrace](/images/57729/025-686aba77cd191cc7530d38f644a6999badfdcf99.jpeg)

Code available on [GitHub](https://github.com/elmahio/stacktrace.js) and [npm](https://www.npmjs.com/package/@elmah.io/stacktrace.js).
