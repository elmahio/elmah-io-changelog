We released a new version ([4.0.55](https://www.nuget.org/packages/Elmah.Io.Cli/4.0.55)) of the elmah.io CLI. The new version includes the following change:

- New `sourcemap` command to automate uploading source maps and minified JavaScript files to elmah.io. The [documentation](https://docs.elmah.io/cli-sourcemap/) has been extended to cover the command and there's a new section explaining how to upload source maps here: https://docs.elmah.io/sourcemaps/#upload-from-the-elmahio-cli.
