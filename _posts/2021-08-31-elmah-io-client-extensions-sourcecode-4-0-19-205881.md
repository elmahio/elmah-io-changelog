We released a new version ([4.0.19](https://www.nuget.org/packages/Elmah.Io.Client.Extensions.SourceCode/4.0.19)) of the `Elmah.Io.Client.Extensions.SourceCode` package. The new version includes the following changes:

- Support for delegates in type names.
- Include filename in the bundled source code (will show up on the elmah.io UI eventually).
- `useCacheIfPossible` flag to control the internal cache.
