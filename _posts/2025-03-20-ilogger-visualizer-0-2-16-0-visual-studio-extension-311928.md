There's a new version of our [ILogger Visualizer extension for Visual Studio](https://marketplace.visualstudio.com/items?itemName=elmahio.loggervisualizer) available on the Visual Studio Marketplace. ILogger Visualizer helps you debug Microsoft.Extensions.Logging configuration during debugging. The new version includes support for the non-generic use of `ILogger`.
