There is a [new stable version](https://www.nuget.org/packages/elmah.io.umbraco/3.3.46) of the elmah.io integration with Umbraco. The major change in the new version is support for Umbraco 8. To use `Elmah.Io.Umbraco` from Umbraco 7, please install version `3.2.35. New features will be added exclusively for Umbraco 8.
