elmah.io now has an [AI plugin](https://github.com/elmahio/elmah-io-ai-plugin) that connects MCP-compatible editors like Cursor and Claude Code directly to your logs. Debug production errors, verify deployments, and check uptime status without leaving your editor, using built-in skills and a deployment watchdog agent that flags regressions for 30 minutes after each release.

Check out how to install it here: [https://docs.elmah.io/elmah-io-ai-plugin/](https://docs.elmah.io/elmah-io-ai-plugin/)
