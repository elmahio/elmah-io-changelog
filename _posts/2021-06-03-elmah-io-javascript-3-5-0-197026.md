We released a new version ([3.5.0](https://www.npmjs.com/package/elmah.io.javascript/v/3.5.0)) of the `Elmah.Io.JavaScript` package. The new version includes the following changes:

- Support for [Breadcrumbs](https://docs.elmah.io/logging-to-elmah-io-from-javascript/#breadcrumbs).
- New [Vue.js sample](https://github.com/elmahio/elmah.io.javascript/tree/main/samples/Elmah.Io.JavaScript.VueJs).
