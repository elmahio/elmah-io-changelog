We released a new version ([4.1.22](https://www.nuget.org/packages/Elmah.Io.Functions/4.1.22)) of the `Elmah.Io.Functions` package. The new version includes the following changes:

- More options for setting hostname on errors.
- Running on the newest version of the `Elmah.Io.Client` package.
- Include readme in the NuGet package.
- Building on .NET 6 and new .NET 6 samples.
