We released a [new version](https://www.nuget.org/packages/Elmah.Io.Cli/5.2.91) of the [elmah.io CLI](https://docs.elmah.io/cli-overview/). The tool now supports exporting log messages from elmah.io to a CSV file:

```
elmahio export --format csv ...
```

Both the inline tool help and the [documentation](https://docs.elmah.io/cli-export/) has been updated to reflect the new feature.
