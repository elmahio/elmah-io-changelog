We released a new version ([3.10.122](https://www.nuget.org/packages/Elmah.Io.AspNetCore/3.10.122)) of the `Elmah.Io.AspNetCore` package. The new version includes the following changes:

- Hostname now set to the machine name rather than the domain name to make it consistent across different loggers.
- Tag helper for `elmah.io.javascript` updated to `3.2.0`.
- Added missing documentation on a range of classes and methods.
- `UseElmahIo` now throws an exception if `AddElmahIo` hasn't been called.
- More ways to fill the `url` field rather than only looking at `Request.Path`.
- Running on the latest stable version of `Elmah.Io.Client`.
