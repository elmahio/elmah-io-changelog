We released a new version ([3.4.51](https://www.nuget.org/packages/elmah.io.umbraco/3.4.51)) of the `Elmah.Io.Umbraco` package. The package fixes a bug that would cause a runtime error when installing the `Elmah.Io.Umbraco` package and not setting up the elmah.io notification method in `healthcheck.config`.
