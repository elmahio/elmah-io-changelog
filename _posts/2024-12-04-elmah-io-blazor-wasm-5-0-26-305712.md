We released a new version ([5.0.26](https://www.nuget.org/packages/Elmah.Io.Blazor.Wasm/5.0.26)) of the `Elmah.Io.Blazor.Wasm` package. The new version includes the following changes:

- Include inspector and custom data.
- Added Support for `OnFilter` and `OnMessage`.
- Added a new `AddElmahIo` method that will allow for configuration through settings.
- New samples for .NET 8 and 9.
- General code improvements by fixing all code suggestions.
