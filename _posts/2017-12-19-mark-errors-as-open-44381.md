You may have noticed the new issue tracker on elmah.io already. If not, check out [this post](https://blog.elmah.io/mark-errors-as-fixed-dashboards-and-more/). With the recent change, you can mark an already fixed error as open (unfixed):

![markopen.gif](/images/44381/928-4b3b6d6e7f6031b1615e9e5cf5a6579553ba7ec1.gif)

Notice that you don't need to manually re-open errors if they reoccur. This feature is there to help you re-open an error that you for some reason don't want marked as fixed.
