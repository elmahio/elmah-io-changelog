We released a new version ([3.11.17](https://www.nuget.org/packages/Elmah.Io.AspNetCore/3.11.17)) of the `Elmah.Io.AspNetCore` package. The new version includes the following changes:

- Build moved from AppVeyor to GitHub Actions.
- SourceLink support on NuGet package.
- Running on the newest version of the `Elmah.Io.Client` package.
- Updated samples for all LTS versions of ASP.NET Core plus a .NET 5 sample.
- Tag helper for `Elmah.Io.JavaScript` now references [3.3.1](https://github.com/elmahio/elmah.io.javascript/releases/tag/3.3.1).
