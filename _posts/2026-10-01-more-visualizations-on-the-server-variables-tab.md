We've added visualizers for a few more values on the *Server Variables* tab:

- `Accept-Language` shows a flag and the language name next to each entry, like `en-US,en;q=0.9`.
- `sec-ch-ua` and `sec-ch-ua-full-version-list` show the browser name and version with a browser icon.
- `sec-ch-ua-platform` shows an icon for the operating system, like Windows.
- `sec-ch-ua-mobile` shows a device icon and whether the value means true or false.
