We released a new version ([4.3.26](https://www.nuget.org/packages/Elmah.Io.Log4Net/4.3.26)) of the `Elmah.Io.Log4Net` NuGet package. The new version includes the following changes:

- Set new Category property from category property or log4net's logger name.
- Running on the newest version of `Elmah.Io.Client`.
