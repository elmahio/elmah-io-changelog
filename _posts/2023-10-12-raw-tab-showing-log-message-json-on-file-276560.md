A new *Raw* tab is available on the extended log message details view. The *Raw* tab shows the raw JSON we have stored which is used to generate the UI. This is probably not a view you are going to launch all the time, but it can be used for various purposes like debugging why a log message is shown as it is or to get a quick overview of all of the details in one place.
