We added more columns to the new *Customize columns* feature. As part of this change, we pulled out the HTTP method (previously part of *URL*), and the application name (previously part of *Message*). You can add both columns back in if you want to see the method and application on the search view. Having these as individual columns will make it possible to sort log messages by these properties too (wasn't possible previously since they were part of another column).
