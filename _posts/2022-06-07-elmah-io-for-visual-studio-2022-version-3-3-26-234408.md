There's a new version of the elmah.io extension for Visual Studio 2022 ([3.3.26](https://marketplace.visualstudio.com/items?itemName=elmahio.elmahiobrowser2022)). The new version includes the following changes:

- Syntax highlighted/formatted stack traces on the log message details view.
- Added severity and version on the log message details view.
- Show an error counter in the lower right corner of the C# editor to indicate how many errors include the file being edited.
- Fixed missing icons when running Visual Studio in dark mode.
