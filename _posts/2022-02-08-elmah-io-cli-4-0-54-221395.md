We released a new version ([4.0.54](https://www.nuget.org/packages/Elmah.Io.Cli/4.0.54)) of the elmah.io CLI. The new version includes the following changes:

- New `deployment` command to automate creating new deployments on [elmah.io Deployment Tracking](https://elmah.io/features/deployment-tracking/). The [documentation](https://docs.elmah.io/cli-deployment/) has been extended to cover the command and there's a new page explaining how to create deployments using the CLI on a build server: [https://docs.elmah.io/create-deployments-from-cli/](https://docs.elmah.io/create-deployments-from-cli/).
- Support for suppressing logo and copyright message using the `--nologo` paramter.
