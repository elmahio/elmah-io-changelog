We have migrated the final suggestion log messages to recommendations. Messages from the SSL checks and ELMAH checks are now created as recommendations on the tab with the same name on the Log Search page. Like the previous recommendations, these messages are still created as both log messages and recommendations. Once we add new notification methods for recommendations, the log message creation will be removed.
