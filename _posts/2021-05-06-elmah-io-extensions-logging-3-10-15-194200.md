We released a new version ([3.10.15](https://www.nuget.org/packages/Elmah.Io.Extensions.Logging/3.10.15)) of the `Elmah.Io.Extensions.Logging` package. The new version includes the following changes:

- Running on the newest `Elmah.Io.Client` package.
- Added support for using objects as scope variables.
- Support for setting application name in options.
- Support for setting correlation id from properties.
- Some additional documentation.
