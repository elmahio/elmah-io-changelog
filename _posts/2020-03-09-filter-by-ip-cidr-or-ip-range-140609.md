There's a new filter in town: IP Filter. Using the new filter you can ignore any log message coming from one or more IP addresses. The filter can be specified using either a single IP, an IP range or a CIDR:

![Filter by IP range](/images/140609/427-f5047317d8dda75ee225287baf4da830a60783c6.gif)

The new IP filter is much more advanced than the IP Filter app available on the *Apps* tab, why we have deprecated the IP Filter app. Please switch to using the new IP Filter on the *Filters* tab.
