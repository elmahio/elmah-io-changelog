We released a new version ([5.1.47](https://www.nuget.org/packages/elmah.io/5.1.47)) of the `Elmah.Io`, `Elmah.Io.AspNet`, `Elmah.Io.Mvc`, and `Elmah.Io.WebApi` packages. The new version includes the following changes:

- Building on .NET 8.
- Newest `Elmah.Io.Client`.
- Upgraded `Microsoft.SourceLink.GitHub` to `8.0.0`.
- Several code improvements after running Sonar checks. This is all internal so no need for code changes are required by you.
