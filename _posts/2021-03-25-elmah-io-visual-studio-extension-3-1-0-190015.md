There's a new version of the [elmah.io extension for Visual Studio](https://marketplace.visualstudio.com/items?itemName=elmahio.elmahio). The new version contains several improvements:

- Environment shown in the logs dropdown.
- Auto-search when selecting a log.
- Support for multiple logs with the same name.
- Order logs by environment and name in the dropdown.
- Show color, environment, and name of the selected log in the search bar. Clicking the details will open the log on app.elmah.io.
