We released a new version ([3.6.82](https://www.nuget.org/packages/elmah.io.nlog/3.6.82)) of the `Elmah.Io.NLog` package. Here are the included new features and bugfixes:

- Target `netstandard2.0` to reduce dependencies for newer .NET and .NET Core apps.
- Use NLog's `${environment-user}` to fill the user field.
- Newest `Elmah.Io.Client`.
- Forward errors during communication with the elmah.io API to NLog's `InternalLogger`.
- Increased timeout unless explicit set through TaskTimeoutSeconds.
- Fixed a bug that would cause web-related errors in the internal log when using the package from a console app.
