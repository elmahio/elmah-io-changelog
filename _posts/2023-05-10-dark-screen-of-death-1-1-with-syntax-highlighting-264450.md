If you are not already familiar, we have published a free Chrome Extension that improves the developer exception page part of ASP.NET Core (also known as the White Screen of Death). With the latest release, stack traces are now syntax highlighted. Existing installations will be auto-updated but if you haven't already, give it a try here: https://chrome.google.com/webstore/detail/dark-screen-of-death/mgjlgekjoadppmakbgjkpmplgpplhejj
