We released a new version ([4.2.21](https://www.nuget.org/packages/elmah.io.umbraco/4.2.21)) of the `Elmah.Io.Umbraco`NuGet package. Unless serious security issues are found, new features will be added to the v5 package only (supporting Umbraco 10 and newer). The new version includes the following changes:

- Running on the newest versions of the `Elmah.Io`, `Elmah.Io.Client`, and `Serilog.Sinks.ElmahIo` NuGet packages.
- Build script modernization and package validation.
