We released a new version ([4.1.36](https://www.nuget.org/packages/Elmah.Io.Client.Extensions.SourceCode/4.1.36)) of the `Elmah.Io.Client.Extensions.SourceCode` NuGet package. The new version includes the following changes:

- Support for files with non-Windows line endings (like Unix).
- Build script modernization, build on .NET 7, and package validation.
- Running on the newest version of `Elmah.Io.Client`.
