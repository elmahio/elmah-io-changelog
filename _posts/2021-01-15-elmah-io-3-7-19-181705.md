We released a new version ([3.7.19](https://www.nuget.org/packages/elmah.io/3.7.19)) of the `Elmah.Io` package. The new version includes the following changes:

- Build moved from AppVeyor to GitHub Actions.
- SourceLink support on NuGet package.
- Running on the newest version of the `Elmah.Io.Client` package.

New versions of the helper packages [Elmah.Io.Mvc](https://www.nuget.org/packages/Elmah.Io.Mvc/3.7.19), [Elmah.Io.WebApi](https://www.nuget.org/packages/Elmah.Io.WebApi/3.7.19), and [Elmah.Io.AspNet](https://www.nuget.org/packages/Elmah.Io.AspNet/3.7.19) have been released as well.
