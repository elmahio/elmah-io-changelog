We released a new version ([3.1.7](https://www.nuget.org/packages/Elmah.Io.Heartbeats.Hangfire/3.1.7)) of the `Elmah.Io.Heartbeats.Hangfire` package. The new version includes the following changes:

- Build moved from AppVeyor to GitHub Actions.
- SourceLink support on NuGet package.
- Running on the newest version of the `Elmah.Io.Client` package.
- New sample for ASP.NET Core 3.1.
