There's a new feature available on the log page: custom buttons. You can insert a custom link for each log on the log settings page. The link destination can be anything from the website logging messages to a GitHub repository or an Azure resource URL. This will give you quick access to external systems you typically visit when also browsing errors inside elmah.io. The custom link will appear as a button on both log search and log settings:
